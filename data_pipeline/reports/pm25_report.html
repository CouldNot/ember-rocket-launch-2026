Next-hour PM2.5 concentration research

This model uses a fixed Beijing reference monitoring station. It does not assess firefighter health, fitness for duty, or evacuation. It must not be applied directly to ten-second SPS30 readings, mobile fireground observations, or personal exposure streams.

The selected model is histgb_leaf15, chosen using validation MAE. Features use only past PM2.5 lags, rolling statistics, and change rates. No weather, CO, person identity, or future readings are included.

The selected model did not improve test MAE over persistence. Its small validation improvement did not carry through to the final test period. This result does not support a claim of better forecast accuracy.

The nominal 90% residual interval covered 89.70% of test targets. Its calibrated half-width is 26.5765 µg/m³, with the lower bound clipped to zero. Temporal dependence and distribution shift prevent a guarantee of future coverage. This interval is not a health probability.

Each forecast uses 25 consecutive hourly observations from t−24 through t to predict t+1. Missing windows or targets are excluded, never imputed. Partitions are assigned by target time; previously observed context may cross a split boundary. The source calendar is interpreted as UTC+08:00 because the official page does not explicitly specify its timezone.

Held-out example

The calendar segment was fixed independently of forecast scores. Each hour makes a fresh one-step forecast from the observations then available; this is not a recursive multi-step forecast. Full test statistics use all 7,925 eligible test windows.

Reproduce and inspect

Run python pm25_model.py --train to download the official source when absent, verify its pinned checksum, and reproduce training. Run python pm25_model.py --demo for a packaged held-out history. The inference interface requires the explicit uci_beijing_reference domain and a valid hourly history. Git excludes raw archives and bulk CSV data.
